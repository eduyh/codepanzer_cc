# CodePanzer.py - Code Your Tank, Command the Arena.

**CodePanzer.py** は、2Dグリッド上に命令チップを並べて戦車の自律 AI を設計し、リアルタイムに戦わせる対戦シミュレータです。

グリッド形状のフローチャートと **Python 構文**（`if / else`、`for`、`while`、変数演算、`def sub_a():` サブルーチン、`print()` デバッグなど）がリアルタイムに双方向連動しており、プログラミングの基礎から自律ロボット制御アルゴリズムまで直感的に学ぶことができます。

---

## 1. 起動方法と動作環境

### 方法 A: ポータブル版をブラウザで直接起動（推奨・インストール不要）
Node.js や Python の環境構築は不要で、オフライン環境でブラウザだけで動作します。

1. `dist/index.html` または配布アーカイブ（`vstank-portable.zip`）を展開したフォルダ内の **`index.html`** をダブルクリック、または Web ブラウザへドラッグ＆ドロップします。
2. 対応ブラウザ: Google Chrome / Microsoft Edge / Safari / Firefox（WebGL 対応環境・非対応時は 2D Canvas に自動フォールバック）

### 方法 B: 開発環境から起動（ソースコード編集・テスト）
Node.js (v18 以上推奨) 環境でリポジトリをクローンして実行します。

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動
npm run dev

# ユニットテストの実行 (Vitest)
npm test

# 型チェックと本番ビルド
npm run build

# 単一 HTML + tanks/ フォルダ一式のポータブル ZIP パッケージを生成
npm run package
```

## 2. システムと動作の仕組み

### 2Dグリッドプログラミング × Python コード双方向連携
- **4方向隣接接続**: グリッド内の各ブロックから、上下左右に隣接するグリッドへのみ矢印（緑: `next`、青: `T / True`、赤: `F / False`）を接続して思考フローを組みます。
- **CPU グリッドサイズ**: 入門向けの **4×4**（最大16ブロック / 16 step/t）から **6×6**（24 step/t）、**8×8**（48 step/t）、大規模アルゴリズム向けの **12×12**（96 step/t）まで選択できます。
- **コード変換 (Code) と直接編集**: 右サイドバーを「コード変換 (Code)」へ切り替えると、現在のグリッド配線に対応する Python コードがリアルタイム表示され、「直接編集・貼付」モードから Python 風コードを貼り付けてグリッドへ自動変換・配置することもできます。
- **デバッグ支援と視認性**: 各チップの `print()` デバッグ出力を ON にすると、実行中に戦車の頭上に吹き出しで変数値や分岐状態が表示されます。また上部バーから画面全体の文字サイズ（**標準 / 大 / 特大**）を切り替えられます。

### 3軸独立制御・戦場メカニクス
シミュレーションは基本 **20 TPS（1秒 = 20 Tick `t`）** で進行します（倍速 `0.25x` 〜 `4x`、一時停止、1 Tick コマ送り対応）。

| 要素 | 仕様・動作 |
| :--- | :--- |
| **3軸独立制御** | **車体 (Body)**・**砲塔 (Turret)**・**レーダー (Radar)** をそれぞれ独立して旋回可能 |
| **座標モード** | **相対座標 (`relative`)**（自機/砲塔正面を `0°` とする相対角）と **絶対座標 (`absolute`)**（北 `0°` / 東 `90°` / 南 `180°` / 西 `270°`）を切替可能 |
| **方向別装甲** | 砲弾の着弾方向に応じてダメージ倍率が変化（**正面 `0.8x`** / **側面 `1.0x`** / **背面 `1.25x`**） |
| **シャシーと積載量** | **軽量** (`HP90 / 積載76t`)・**標準** (`HP130 / 積載100t`)・**重量** (`HP190 / 積載135t`) に加え、砲塔固定＆主砲冷却+20%の **超重** (`HP210 / 積載160t`) を選択可能。総重量超過時は移動・旋回速度にペナルティ |
| **レーダー視界と記憶** | **広角 (`120° / 480px`)**・**標準 (`50° / 820px`)**・**狭角 (`22° / 1550px`)** の3種。視界外に出ると **28t** 後に捕捉記憶が消滅（古い記憶では偏差射撃の精度が減衰）。`under_lock()` で被ロック、`hit_from()` で被弾方向を検知可能 |
| **近接・衝突処理** | `proximity_near()` で全周の壁・障害物・他戦車をスキャン（接近時・左右比較・左手法/右手法対応）。壁接触時は壁沿いに滑走し法線衝突速度のみでダメージ発生。車両同士の衝突時は実重量比・相対運動量に応じた弾き返し・接触ダメージとシャシー別の方向逸らし（連続膠着時は段階エスカレーション＋接線スリップ＋時間窓付きシードで引き剥がし、壁・障害物境界へ再クランプ）を行い、正面の安定した重量級でも側面・背面からの高速突入時には車体角を大きく揺らせる |
| **主砲 (Main Gun)** | **軽量砲** (`P=0.5/1.0/1.5`)・**標準砲** (`P=1.0/1.8/2.5`)・**重量砲** (`P=2.0/2.5/3.0`) の3種に対し、`fire_main(power="fast" \| "normal" \| "heavy")` の **速弱 / 標準 / 遅強** 3段階を指定（実効威力・弾速・冷却Tickは装備構成に応じて自動算出） |
| **Special (SP) 兵装** | **装備なし** (`0t`)・**煙幕**（視界遮断100t・3回 / `9t`）・**緊急ブースト**（50t・速度/旋回1.7倍 3回 / `10t`）・**デコイ**（HP25おとり150t・3回 / `11t`）・**地雷**（5発 / `12t`）・**バリア**（120t・被ダメ60%減 3回 / `15t`）・**誘導ミサイル**（4発 / `16t`） |
| **戦場サイズ** | **極小 (`600×480`)**・**小 (`840×660`)**・**中 (`1100×860`)**・**大 (`1400×1100`)** の4段階 |
| **対戦・勝敗判定** | テストグラウンドでは **最大8台** のバトルロイヤルおよび **1 vs 多のチームバトル** に対応。敵機自滅や未発射タイムアウト時は誤って撃破勝利にならず **引き分け (`DRAW`)** / 判定扱いに厳密判定 |

## 3. カリキュラム構成（課題学習・開発訓練・機体開発）

上部モード切替から **「課題学習」「開発訓練」「機体開発」** の 3つの学習・開発モードを切り替えられます。課題学習・開発訓練ではステージごとに必要最小限のチップがパレットに表示され（必要に応じて「全チップを表示」も可能）、「ヒント」や「模範解答」ボタンでいつでも参照できます。

### 課題学習（全4回・24ミッション）
基礎構文から自律アルゴリズムまで、2パターン自動検証やチェックポイント走破を通じて段階的に習得します。

| 回 | テーマ | ミッション | 主な学習内容 |
| :---: | :--- | :---: | :--- |
| **第1回** | 順次処理・`for`文・砲塔操作 | `1-1` 〜 `1-6` | 直進・停止 `stop()`・`turn_body(wait=True)`・`time.sleep()`・`for i in range(4):`・砲塔独立操作・固定砲塔 (`destroyer`) |
| **第2回** | センサー・条件分岐 (`if/elif/else`) | `2-1` 〜 `2-6` | 前方壁回避・色タイル分岐 (`on_tile(..., edge=True)`)・3色多段分岐・`proximity(approaching)` スラローム・ミッション状態切替・左手法 (`left_open`) 迷路踏破 |
| **第3回** | 変数・乱数・状態遷移・`while`文 | `3-1` 〜 `3-6` | カウンタ `a += 1` (`a == 3`)・状態遷移 (`mode = 0 / 1`)・`while not enemy_detected():` 全方位索敵・偏差予測 (`lead="lead"`) ループ・`random.randint()` 回避・総合実戦テスト |
| **第4回** | サブルーチン・絶対座標・総合試験 | `4-1` 〜 `4-6` | `def sub_a():` 再利用・複数サブルーチン役割分担・絶対方位モード (`heading`)・パーツ最適化タイムアタック・二重周回コース・修了総合試験 |

### 開発訓練（全4部・19ステージ）
課題学習で身につけた基礎を、**`4×4` 基準・1ステージ1要素のやさしい段階構成** で対人戦・SP兵装戦術へと橋渡しします。

| 部 | テーマ | ステージ / CPU | 主な学習内容 |
| :---: | :--- | :---: | :--- |
| **第1部** | 4×4 基本戦闘＆リアクション入門（60分） | St.1〜6 (`4×4`) | 索敵→照準→発砲ループ・距離制御 (`enemy_dist` 引き撃ち)・被ロック回避 (`under_lock()`)・被弾反転 (`hit_from` / `last_hit`)・壁回避回り込み・第1部卒業戦 |
| **第2部** | 6×6 戦術アルゴリズム拡張（60分） | St.7〜10 (`6×6`) | カウンタ周期回避 (`a % 20 == 0`)・乱数ジグザグ回避・HP連動フェーズ切替 (`hp_percent` → `mode`)・第2部卒業戦 |
| **第3部** | SP兵装 戦術マスター（60分） | St.11〜13 (`4×4`)<br>St.14〜16 (`6×6`) | 全6種SP兵装（誘導ミサイル `missile`・地雷 `mine`・バリア `shield`・煙幕 `smoke`・緊急ブースト `boost`・デコイ `decoy`）と発動センサー (`incoming_shell` / `under_lock` / `sp_cooldown`)・第3部卒業戦 |
| **第4部** | 【自習】特殊シャシー・多対一・卒業検定 | St.17 (`6×6`)<br>St.18〜19 (`8×8`) | 固定砲塔駆逐戦車 (`destroyer`)・1 vs 2 チーム連携戦・シールドエース相手の統合卒業検定 |

## 4. 付属の戦車データ (`tanks/` フォルダ・全31機)

リポジトリおよびポータブル配布版の `tanks/` フォルダには、初期自機1機＋対戦相手・学習用サンプル30機の計 **31種類の `.vstank.json` ファイル** が収録されています。

### 付属ファイルの読み込み・活用方法
- **対戦相手として読み込む**: 「テストグラウンド」上部の **「相手読込」** ボタン、または「共有・読込」モーダルのインポート欄から `tanks/` 内のファイルを複数選択して追加できます（最大8台まで同時対戦可）。
- **自機に読み込んで改造する**: エディタ上部の **「読込」** ボタンから開くか、「共有・読込」モーダル内のテストグラウンド機体一覧から **「自機に読込」** をクリックすると、付属戦車の中身（配線・Pythonコード）を見てそのまま改造できます。
- ご自身が保存した `.vstank.json` ファイルも同じ `tanks/` フォルダに置いておくと、自機としても対戦相手としても共通のライブラリフォルダから開けます。
