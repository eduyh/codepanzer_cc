# CodePanzer.py - Code Your Tank, Command the Arena.

**CodePanzer.py** は、2Dグリッド上に命令チップを並べて戦車の自律 AI を設計し、リアルタイム 3D 戦場で戦わせるプログラミング戦車バトルシミュレータです。

グリッド上のフローチャートと **Python 構文**（`if / else`、`for`、`while`、変数演算、`def sub_a():` サブルーチン、`print()` デバッグなど）がリアルタイムに双方向連動しており、プログラミングの基礎から自律ロボット制御アルゴリズムまで直感的に学ぶことができます。

---

## 1. 起動方法と動作環境

### 方法 A: ポータブル版をブラウザで直接起動（推奨・インストール不要）
Node.js や Python の環境構築は不要で、オフライン環境のままブラウザだけで動作します。

1. `dist/index.html` または配布アーカイブ（`vstank-portable.zip`）を展開したフォルダ内の **`index.html`** をダブルクリック、または Web ブラウザへドラッグ＆ドロップします。
2. 対応ブラウザ: Google Chrome / Microsoft Edge / Safari / Firefox（WebGL 対応環境・非対応時は 2D Canvas に自動フォールバック）

### 方法 B: 開発環境から起動（ソースコード編集・テスト）
Node.js (v18 以上推奨) 環境でリポジトリをクローンして実行します。

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動
npm run dev

# ユニットテストの実行 (Vitest)
npm test

# 型チェックと本番ビルド
npm run build

# 単一 HTML + tanks/ フォルダ一式のポータブル ZIP パッケージを生成
npm run package
```

## 2. システムと動作の仕組み

### 2Dグリッドプログラミング × Python コード双方向連携
- **4方向隣接接続**: グリッド内の各ブロックから、上下左右に隣接するグリッドへのみ矢印（緑: `next`、青: `T / True`、赤: `F / False`）を接続して思考フローを組みます。
- **CPU グリッドサイズ**: 入門向けの **4×4**（最大16ブロック / 16 step/t）から **6×6**（24 step/t）、**8×8**（48 step/t）、大規模アルゴリズム向けの **12×12**（96 step/t）まで選択できます。
- **コード変換 (Code) と直接編集**: 右サイドバーを「コード変換 (Code)」へ切り替えると、現在のグリッド配線に対応する Python コードがリアルタイム表示され、「直接編集・貼付」モードから Python 風コードを貼り付けてグリッドへ自動変換・配置することもできます。
- **デバッグ支援と視認性**: 各チップの `print()` デバッグ出力を ON にすると、実行中に戦車の頭上に吹き出しで変数値や分岐状態が表示されます。また上部バーから画面全体の文字サイズ（**標準 / 大 / 特大**）を切り替えられます。

### 3軸独立制御・戦場メカニクス
シミュレーションは基本 **60 TPS（1秒 = 60 Tick `t`）** で進行します（倍速 `0.25x` 〜 `4x`、一時停止、1 Tick コマ送り対応）。

| 要素 | 仕様・動作 |
| :--- | :--- |
| **3軸独立制御** | **車体 (Body)**・**砲塔 (Turret)**・**レーダー (Radar)** をそれぞれ独立して旋回可能 |
| **座標モード** | **相対座標 (`relative`)**（自機/砲塔正面を `0°` とする相対角）と **絶対座標 (`absolute`)**（北 `0°` / 東 `90°` / 南 `180°` / 西 `270°`）を切替可能 |
| **方向別装甲** | 砲弾の着弾方向に応じてダメージ倍率が変化（**正面 `0.8x`** / **側面 `1.0x`** / **背面 `1.25x`**） |
| **レーダー視界と記憶** | レーダー視野角・射程内の敵のみ捕捉し、視界外に出ると **12t** 後に捕捉記憶が消滅。`under_lock()` で敵から狙われているか検知可能 |
| **主砲 (Main Gun)** | `fire_main(power=0.5~3.0)` で威力・弾速・クールダウンが変化（高威力ほど大ダメージ＆長冷却） |
| **Special (SP) 兵装** | **誘導ミサイル**（4発 / クールダウン `150t`）・**地雷**（5発 / クールダウン `90t`）・**バリア**（3回 / 効果 `120t` でダメージ60%軽減 / クールダウン `240t`） |
| **戦場サイズ** | **極小 (`600×480`)**・**小 (`840×660`)**・**中 (`1100×860`)**・**大 (`1400×1100`)** の4段階 |
| **対戦・勝敗判定** | テストグラウンドでは **最大8台** のバトルロイヤルおよび **1 vs 多のチームバトル** に対応。敵機自滅や未発射タイムアウト時は誤って撃破勝利にならず **引き分け (`DRAW`)** / 判定扱いに厳密判定 |

## 4. 付属の戦車データ (`tanks/` フォルダ・全12機)

リポジトリおよびポータブル配布版の `tanks/` フォルダには、初期自機1機＋対戦相手・学習用サンプル11機の計 **12種類の `.vstank.json` ファイル** が収録されています。

### 付属ファイルの読み込み・活用方法
- **対戦相手として読み込む**: 「テストグラウンド」上部の **「相手読込」** ボタン、または「共有・読込」モーダルのインポート欄から `tanks/` 内のファイルを複数選択して追加できます（最大8台まで同時対戦可）。
- **自機に読み込んで改造する**: エディタ上部の **「読込」** ボタンから開くか、「共有・読込」モーダル内のテストグラウンド機体一覧から **「自機に読込」** をクリックすると、付属戦車の中身（配線・Pythonコード）を見てそのまま改造できます。
- ご自身が保存した `.vstank.json` ファイルも同じ `tanks/` フォルダに置いておくと、自機としても対戦相手としても共通のライブラリフォルダから開けます。
